# Between-session advice

Use a private working directory outside this public repository. Ask which save slot to use if it is not established. Run `node advisor.ts <save-directory> <private-output-directory>` from this directory, and read both `digest.md` and `mechanics.md`. The reader copies the source before parsing; it does not write to the save. Refresh after each save. Check version warnings before applying a rule.

Cite digest field paths and values for every save-based claim and cite a rule ID for every mechanic. For customers use `customersById` paths, so citations survive reordering. A rule marked unverified is not established for the installed build. Distinguish raw saved values, estimates, and predictions. Do not infer missing fields or turn unknowns into zero. State a measurable prediction and its interval before play. A per-day delta needs two snapshots and elapsed in-game days; the first snapshot is only a baseline.

After play, save and sync, re-run the digest, compare the chosen metric over the specified interval, and record results and mechanics the player rejects. Keep saves, digests, briefs, and manifests out of the repository. A structured private brief can be checked with `node lint-brief.ts <brief.json> <digest.json>`; each play needs an action, a prediction beginning `Prediction:`, digest JSON pointer/value citations, and mechanic rule IDs. Lint checks references, not strategic correctness or whether a mechanic applies to the current build.
